# Ariadne — Vision

## One-liner

**Ariadne coordinates the AI workforce teams already use.**

## The problem

People increasingly run multiple AI agents simultaneously — Claude for reasoning, GPT for drafting, Codex for code — because different agents are good at different things. The human becomes the middleware:

Claude → you → GPT → you → Codex → you → GitHub

You carry context between systems, assign work, review outputs, decide what happens next. The coordination is manual, invisible, and unscalable.

## The thesis

- **Coordination is the product. The dashboard is only the visibility surface.**
- Ariadne is not a place to chat with models. It is the coordination layer between agents: shared context, task assignment, agent-to-agent handoffs, human approval gates, audit trail.
- Bring your own agents. Ariadne does not replace Claude or GPT — it gives them a shared work environment.

## What Ariadne is NOT

- Not a model wrapper ("Claude + GPT in one chat box")
- Not a dashboard of agents with no real coordination
- Not a platform with 50 built-in agents

## Phase 1: prove the thesis with the smallest possible thing

Two agents. One workflow. Real handoffs. One human approval gate. If a team watches Scout's research flow into Maker's draft, reviews it, approves it, and thinks "I want this for my actual work" — the thesis is validated.

## Naming note

Ariadne gave Theseus the thread to navigate the labyrinth. Shared context is the thread that keeps every agent from getting lost.
