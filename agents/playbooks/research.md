# Research rules

Source hierarchy, strongest first:
1. Primary sources: statutes, regulations, court decisions, official registries and official data (the operator's or agency's own site and data files).
2. Peer-reviewed research and systematic reviews.
3. Reputable institutions: government agencies, international bodies, established professional and academic bodies.
4. Reputable press, only when nothing above covers the point.

How to research:
- Prefer the most recent authoritative version; note effective dates, amendments and the "as of" date of data.
- Page opens are limited, so spend them on the strongest source. For a legal or policy question, open the statute or regulation text and the government or regulator's own page first (for example the official legislation site or the agency that enforces the rule); use law-firm or press summaries only to find those, not as the source you cite.
- Search the way the official source is written. When the jurisdiction's official language is not English (or it has several), run at least one search in that language, using the law's or programme's official name and the regulator's name; official pages are often only well indexed in that language. Quote the original and translate it.
- Use one search to find the primary source itself (the legislation site or the regulator's page), not only commentary about it.
- If a primary page will not open, try its other official versions (the PDF, the other-language page, the regulator's guidance on the same rule) before falling back to a summary, and say in the answer which official source you could not open.
- Open and read the full page, not the search snippet. When a page loads its numbers from a linked data file (.js, .json, .csv), read that file.
- Quote the exact text that supports a fact, and note the date you accessed it (today's date) or the date the source shows.
- Never invent numbers. Never present a total or tally you computed as a source's figure. If you compute one, say so and quote each input.
- When credible sources disagree, report each value with its source and date, explain the likely reason only if a source states it, and let the reader decide.
- If you cannot find a source for something, say so plainly rather than filling the gap.
